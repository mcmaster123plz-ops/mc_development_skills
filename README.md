# mc_development_skills

个人工作技能仓库。沉淀可以复用、能够说明依据和适用条件的工作方法，依据实际使用反馈逐步改进。

## 已发布技能

| 技能 | 版本 | 用途 |
|---|---|---|
| [报告撰写工作台](skills/report-workbench/SKILL.md) | 0.2.0 | 结合项目需求设计框架，核对资料、组织证据并编写修订各类工作报告 |

## 报告撰写工作台能做什么

同时推进资料确认与框架设计，适用于工作总结、调查评估、技术方案、专题分析和周期报告。没有现成模板时先给出结构建议和资料需求；已有模板时根据参考用途提取结构与样式。局部修改直接处理，复杂任务才建立必要台账。

支持图文素材关联、周期更新和修改影响检查。Python 辅助脚本只使用标准库，用于关联、指纹和 DOCX 结构检查；不会自动证明业务结论，也不承担全部排版渲染。

## 安装和使用

在支持 skill-installer 的 Codex 中输入：

```text
使用 $skill-installer 安装 https://github.com/mcmaster123plz-ops/mc_development_skills/tree/main/skills/report-workbench
```

安装后可这样提出任务：

```text
使用 $report-workbench。我要提交一份阶段工作报告，暂时没有模板。
请结合当前项目任务和已有资料，先建议框架，说明各章需要什么证据，再继续撰写。
```

也可以在已建立的报告任务中请求换期、换图、改数或调整框架。不要向公开 issue 提交客户报告、原始数据、个人路径或未获授权的资料。

## 检查

需要 Python 3.10 或更高版本，无第三方 Python 依赖。在仓库根目录运行：

```text
python -m unittest discover -s tests -p "test_*.py" -v
```

测试使用独立合成资料和最小 DOCX 结构，不含真实业务文件。它验证脚本的部分行为，不代表跨行业报告质量已得到验证。

## 如何完善

反馈请说明使用场景、预期、实际结果及可匿名复现的输入。按“通用方法—报告类型—项目要求”判断修订位置。公开版本只保留可泛化内容，项目规则由使用者在项目内维护。

详见 [贡献说明](CONTRIBUTING.md)和[版本记录](CHANGELOG.md)。本技能目前为早期版本，跨项目效果仍需通过实际任务验证。

技能结构、调用和安装方式参考 [OpenAI 官方文档](https://learn.chatgpt.com/docs/build-skills)。仓库发布提供源代码与安装入口，不代表已进入插件目录。
